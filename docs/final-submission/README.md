## Submission guardrails

- The final submission MUST show a mobile application, not only the existing desktop client.
- The final video MUST be Unlisted and MUST show only implemented functionality.
- The function list MUST distinguish Implemented, Planned, and Out of Scope items.
- The contribution record MUST use real issues, pull requests, commits, tests, and demo evidence.
- Keep the final repository private before submission.
- Do not commit a PAT, password, signing key, or local API address.
- The course deadline is 2026-12-07 21:00. The read-only PAT MUST remain valid for at least two weeks after the deadline. Set its expiry no earlier than 2026-12-21; 2026-12-31 provides safer review time.
